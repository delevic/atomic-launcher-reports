# Atomic Launcher — Bug Reports

Public bug reports and testing feedback for Atomic Launcher.

[Report a bug](https://github.com/delevic/atomic-launcher-reports/issues/new?template=bug_report.yml) · [Browse reports](https://github.com/delevic/atomic-launcher-reports/issues)

## Report a problem — V72IE and later

1. Open **Settings → Report a bug** in Atomic Launcher.
2. Describe what happened. If useful, record the problem and review the video.
3. Tap **Send report → Save & continue**, then choose where to save the diagnostic ZIP.
4. GitHub opens with the report title, description, launcher build, device details and ZIP filename filled in.
5. Sign in to GitHub if needed. **Attach the ZIP you saved**, review the form, and submit the issue.

The ZIP is **not attached automatically**. Saving it or opening GitHub does not submit an issue. The launcher cannot confirm whether you finished submitting in the browser. If the description is too long for the link, the form contains a shortened preview; the complete description remains in `report.txt` inside the ZIP.

A GitHub account is required. The ZIP can include launcher diagnostics, device information, and any recording or screenshot you chose to include. **Reports and attachments here are public.** Review them before uploading.

GitHub accepts ZIP attachments up to 25 MB. If the ZIP is too large, the launcher asks you to shorten the recording or remove the screenshot. You can still save the complete ZIP locally or use **Share ZIP**.

## Other ways to share

- **Save ZIP** saves a local copy without opening GitHub.
- **Send report → Share ZIP** opens Android sharing, for example to send the ZIP directly to the developer.
- On **V72ID and earlier**, save the ZIP and open the **Report a bug** link above manually.

Please report one problem per issue and include the full build marker (for example, `V72IE`), not only `Beta 0.1`.

Automatic sending without a GitHub account or manual attachment requires a separate receiving service. It is not enabled in this build.

## Source code

Launcher source code remains private. This repository contains only reporting instructions and issue forms.

## Prijava na srpskom

U verziji **V72IE** otvorite **Settings → Report a bug**, opišite problem i izaberite **Send report → Save & continue**. Sačuvajte ZIP na telefonu. Otvoriće se popunjen GitHub obrazac: prijavite se, **ručno priložite sačuvani ZIP** i potvrdite slanje.

Samo čuvanje ZIP-a ili otvaranje obrasca ne šalje prijavu. Prijave i prilozi su javni, pa pregledajte snimak i podatke pre kačenja. Za ZIP veći od 25 MB skratite snimak ili uklonite screenshot; ceo ZIP i dalje možete sačuvati ili poslati preko **Share ZIP**.
