# Atomic Launcher — Bug Reports

Public bug reports and testing feedback for Atomic Launcher.

[Report a bug](https://github.com/delevic/atomic-launcher-reports/issues/new?template=bug_report.yml) · [Browse reports](https://github.com/delevic/atomic-launcher-reports/issues)

## Report a problem

1. Open **Settings → Report a bug** in Atomic Launcher.
2. Describe what happened. If useful, record the problem and review the video.
3. Use **Save ZIP** to save the diagnostic report.
4. Open **Report a bug** above, fill in the form, attach the ZIP, and submit it.

A GitHub account is required to submit a report. The ZIP can include launcher diagnostics, device information, and any recording or screenshot you chose to include. **Reports and attachments here are public.** Review them before posting, and remove anything you do not want to share publicly.

One problem per issue makes fixes easier to track. Please include the full build marker shown in the report screen (for example, `V72ID`), not only `Beta 0.1`.

## Current integration

This repository is ready for reports submitted through GitHub. The current launcher **Send report** button opens Android sharing; it does not upload to this repository automatically. Automatic sending without a GitHub account requires a separate receiving service and is not enabled yet.

## Source code

Launcher source code remains private. This repository contains only reporting instructions and issue forms.

## Prijava na srpskom

Prijavu slobodno napišite na srpskom. U launcheru otvorite **Settings → Report a bug**, sačuvajte ZIP preko **Save ZIP**, pa ga priložite uz novu prijavu ovde. Napišite verziju i kako se problem pojavio. Prijave i prilozi su javni, pa pre slanja pregledajte snimak i ostale podatke.
